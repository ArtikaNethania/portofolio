NLP ML

Fake Review Detection System

Mar 2026 – Jun 2026 · NLP / Machine Learning

Compared four NLP approaches — Logistic Regression, SVM, Random Forest, and RoBERTa — on detecting fake hotel reviews, then evaluated cross-domain generalization on Yelp data.

  • Trained and compared 4 models on 1,600 hotel reviews (Deceptive Opinion Spam Corpus); best in-domain accuracy 89.69% (Logistic Regression)
  • Cross-domain evaluation on 2,483 Yelp reviews — RoBERTa showed best generalization (F1: 0.60 vs. classical models)
  • Deployed as a real-time interactive web app via Streamlit
Python Scikit-learn RoBERTa Transformers Streamlit NLTK
Computer Vision Full Stack

Smart Attendance with Face Recognition

Feb 2026 – Jun 2026 · Computer Vision / Full Stack

Automated attendance system using a custom computer vision pipeline — from face detection and image enhancement to feature extraction and classification.

  • Haar Cascade for face detection → CLAHE for image enhancement → HOG + LBPH feature extraction → XGBoost classification, achieving 98% confidence score
  • FastAPI backend serving real-time predictions; React frontend for live attendance dashboard
  • Handles varying lighting and image quality through CLAHE preprocessing
Python OpenCV XGBoost FastAPI React LBPH

ML Explainability: SHAP vs LIME

Feb 2026 – Jun 2026 · Explainable AI / Research

Comparative analysis of two XAI methods across two model architectures, measuring consistency, computational cost, and real interpretability.

  • Applied SHAP and LIME to Logistic Regression and Random Forest on the Vertebral Column dataset
  • Analyzed consistency of feature importance rankings, computation time, and explanation stability
  • Found SHAP more consistent for global interpretability; LIME more flexible for local explanations
